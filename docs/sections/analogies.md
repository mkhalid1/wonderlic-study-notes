# Analogies

**In one line:** you work out how two words are related and find the word that completes a second pair in the same way.

Wonderlic names "analogies" among its test topics, and its candidate page uses one as a sample question. Analogies look like vocabulary items, but the words are usually easy. The skill is naming the exact relationship and not settling for a loose one.

## What it measures

Analogies test reasoning with words: can you see a relationship (part to whole, tool to job, young to adult) and carry it over to a new pair? That is pattern-finding, the same skill as a number series, applied to meaning instead of numbers.

## How the questions look

Usually written as **A is to B as C is to ?**, or in short form **A : B :: C : ?**. Five options follow. Some items give a full pair and ask which other pair has the same relationship.

The relationships that come up most on tests of this kind:

| Relationship | Example |
|---|---|
| Opposites | full : empty |
| Part and whole | wheel : car, petal : flower |
| Worn on or used with | glove : hand |
| Tool and its job | saw : cut |
| Maker and what is made | baker : bread |
| Young and adult | puppy : dog |
| Group name | bees : swarm |
| Measuring tool and what it measures | clock : time |
| Smaller unit and larger unit | inch : foot |
| Worker and workplace | chef : kitchen |
| Letter or number patterns | AC : BD |

## A method that works

1. **Make a sentence that links the first pair.** "A glove is worn on a hand." Be specific: "goes with" is too loose, because almost anything goes with anything.
2. **Put the third word into the same sentence.** "A sock is worn on a ___."
3. **Test every option in the sentence.** Only one should make it true. If two fit, your sentence is too loose. Make it tighter and test again.
4. **Check the order.** If the first pair runs part to whole, the second pair must run part to whole too, not whole to part.
5. **For "which pair" questions,** make the sentence for the given pair, then try it on each option pair in turn.

## Traps that cost points

- **Picking a word from the same topic.** "Den" is about wolves, but the analogy fish : school is about a group name, so the answer is "pack".
- **Reversing the direction.** Author : novel is maker to work. Novel : author would need the reverse.
- **A loose relationship.** "A tadpole is related to water" fits pond and frog equally. "A tadpole grows into a ___" fits only frog.
- **Grammar mismatch.** If the first pair links a noun to a verb, such as knife : cut, the second pair should too.
- **Letter analogies.** Turn letters into positions (A = 1, C = 3) so you can see the step instead of guessing.

## Timing

As guidance: 8 to 12 seconds per item. Saying the linking sentence takes 2 or 3 of those. If two options still seem to fit after you tighten the sentence once, pick the more specific match and move on.

## Practice items

These 5 items are original, written for these notes. They are not taken from the Wonderlic or any publisher's materials. A fair target is 5 items in 1 minute.

**Item 1.** FISH is to SCHOOL as WOLF is to:

A. herd &nbsp; B. flock &nbsp; C. den &nbsp; D. pack &nbsp; E. pride

**Item 2.** THERMOMETER is to TEMPERATURE as SCALE is to:

A. weight &nbsp; B. height &nbsp; C. kitchen &nbsp; D. balance &nbsp; E. speed

**Item 3.** PAGE is to BOOK as ___ is to TRAIN.

A. station &nbsp; B. carriage &nbsp; C. track &nbsp; D. driver &nbsp; E. ticket

**Item 4.** Which pair has the same relationship as KNIFE : CUT?

A. book : read &nbsp; B. chair : table &nbsp; C. shoe : lace &nbsp; D. bread : bake &nbsp; E. pen : write

**Item 5.** AC is to BD as EG is to:

A. FG &nbsp; B. FH &nbsp; C. GI &nbsp; D. EH &nbsp; E. HJ

<details>
<summary>Answers and explanations, items 1 to 5</summary>

**Item 1: D (pack).** A group of fish is a school, and a group of wolves is a pack. *Why not C:* a den is where wolves live, not what a group of them is called.

**Item 2: A (weight).** A thermometer measures temperature, and a scale measures weight. *Why not D:* a balance is another tool for weighing, not the thing being measured.

**Item 3: B (carriage).** A book is made of many pages, and a train is made of several carriages. *Why not C or A:* a train runs on a track and stops at a station, but neither is part of the train.

**Item 4: E (pen : write).** A knife is a tool you use to cut, and a pen is a tool you use to write. *Why not A:* a book is the thing that gets read, not the tool you read with. *Why not D:* bread is the thing that gets baked.

**Item 5: B (FH).** As positions, AC is 1 and 3, and BD is 2 and 4: each letter moves forward one place. EG is 5 and 7, so moving each letter forward one place gives 6 and 8, which is FH.

- **5:** your linking sentences are tight. Keep using them under time pressure.
- **4:** look at the "why not" lines for the items you missed. Most misses on analogies are a same-topic word chosen over the exact relationship.
