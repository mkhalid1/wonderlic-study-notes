# Glossary

Terms you will meet in these notes, on Wonderlic's pages and in your invitation.

| Term | Meaning |
|---|---|
| **Wonderlic Select** | Wonderlic's current pre-employment assessment, with a timed cognitive section and untimed motivation and personality sections |
| **Wonscore** | The former name of Wonderlic Select |
| **Classic cognitive test** | Wonderlic's phrase for the traditional 50-question timed test, scored by number correct |
| **Cognitive ability** | Wonderlic's term for your ability to learn, adapt and solve problems |
| **Motivation section** | The untimed 58-item questionnaire about the kinds of work you find interesting |
| **Personality section** | The untimed 150-item questionnaire about how you react to people, tasks and situations at work |
| **Candidate Feedback Report** | The only result Wonderlic says candidates receive, offered through a link at the end if the employer provides it |
| **Job profile** | The pattern of results that Wonderlic links to success in a given role, built from O\*NET and its own applicant data |
| **O\*NET** | The U.S. Department of Labor's database of job descriptions and requirements |
| **Difficulty weighting** | Scoring that gives harder questions more weight than easier ones, as Wonderlic Select does |
| **Raw score** | The number of correct answers, as on the classic test |
| **Proctored** | Watched by a supervisor, in person or remotely. Wonderlic Select is usually not proctored |
| **Accommodation** | A change to testing conditions for a disability, arranged through the employer under the Americans with Disabilities Act |
| **Series** | A sequence of numbers or letters that follows a rule |
| **Gap** | The difference between two neighbouring terms in a series |
| **Woven series** | Two simple series taking turns in one sequence |
| **Analogy** | A pair of words with a relationship, to be matched by a second pair |
| **Linking sentence** | A short sentence that states the exact relationship in an analogy |
| **Synonym** | A word with a similar meaning |
| **Antonym** | A word with the opposite meaning |
| **Syllogism** | Two statements followed by a conclusion to judge as true, false or not certain |
| **Not certain** | The label for a conclusion that could be true or false, because the statements do not settle it |
| **Affirming the result** | The error of concluding "P" from "if P then Q" and "Q" |
| **Contrapositive** | From "if P then Q", the valid conclusion "if not Q then not P" |
